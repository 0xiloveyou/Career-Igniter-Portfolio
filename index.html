About Me

A developer who enjoys turning messy requirements into simple backend systems.

My programming journey started with curiosity about how websites actually work behind the screen. Over time, that curiosity moved deeper into servers, databases, APIs, authentication, and the logic that keeps real applications dependable.

I enjoy backend work because it rewards clear thinking. I like designing REST APIs, planning database schemas, writing reusable services, and debugging the small details that make software stable.
